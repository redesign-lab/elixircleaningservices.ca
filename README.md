# Elixir Cleaning Services — homepage redesign

A static, mobile-first homepage concept for [Elixir Cleaning Services](https://elixircleaningservices.ca/). Open `index.html` directly or serve the repository root with a static web server. The demo uses `noindex, nofollow`.

## Files

- `index.html` — homepage and original homepage content
- `css/style.css` — responsive styles
- `js/script.js` — accessible mobile menu
- `assets/images/` — original homepage photographs, stored locally
- `assets/logo/` — original logo and a black-background-removed version for the dark header
- `assets/fonts/` — self-hosted Manrope font files and license
- `.nojekyll` — GitHub Pages compatibility

## GitHub Pages

Publish the repository root from the desired branch in **Settings → Pages**, or use a Pages workflow. Local asset paths are relative, including for project subdirectory URLs.

## Source and limitations

Homepage copy, photographs, logo and menu destinations were taken from the existing homepage. The original site's palette includes black, white, `#A19982` and `#f1ede6`. Both original Contact Us menu entries are retained as they point to different source pages. The contact button links to the original contact page rather than claiming a static form can submit. A separate license image could not be identified in the source homepage markup and has not been invented.
